# 0003. npm is the package manager

- **Status:** Accepted
- **Date:** 2026-11-26

## Context

The frontend needs one package manager for local work, `tools/verify/verify.mjs` and CI.

## Decision

npm, the one that ships with Node.js 22. `frontend/package-lock.json` is committed, CI installs
with `npm ci`, and `angular.json` names npm as the CLI's package manager. Versions that must
match an installed binary are pinned exactly: `@playwright/test` is 1.63.0.

## Consequences

No extra tool to install. A change to the package manager changes this ADR, CI and the README.
