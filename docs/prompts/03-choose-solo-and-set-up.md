# Feature: Choose solo and set up the game

Journey 03 of `docs/journeys.md`. Solo Or Friends choice, then maths, tables, tour length and speed.

## Goal

After picking a kid, a child sees Solo Or Friends and chooses "Play solo". Game Setup then
offers the kinds of maths (times tables from 2 to 12, plus, minus and divide), which times
tables, the tour length (6, 12 or 24 desks) and the card speed (Chill, Normal, Lightning). The
defaults start a game with no changes, and the rules of the screen hold (for example, the last
kind of maths cannot be switched off). "Go!" hands the setup to a solo game and opens Duel in
its loading state; journey 04 makes the duel playable. "Play with friends" is shown but its
path is journey 12's.

This journey builds on journeys 01 to 02 in `docs/journeys.md`. Before you start, check
their % complete there and in the code. If one this journey needs is not done, build the smallest
part of it this journey needs first, record that in your summary, and go on.

    passport, stamp.
  - Frontend: current Angular (standalone, signals, `OnPush`, zoneless); `atw-*` selectors;
