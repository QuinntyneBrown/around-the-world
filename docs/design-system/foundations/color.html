Overview

The game is a bright classroom. The page is sky blue, things you read sit on white, and text is navy. Red is the way on. Each of the five kids owns one colour, used for their name tag, their place on the world ring and their timer bar. Colour never carries a state alone: there is always a word, an icon, a tick or a dot with it.

Usage

  • Read a token by its role. Never write a hex value in a component.
  • One red button per screen.
  • A kid’s colour means that kid and nothing else. Do not use Nia’s red for an error or Milo’s green for success.
  • Every state shown by colour is also shown by a word, an icon, a tick or a dot.
  • Never beige or cream.
