Foundation

Typography

Fredoka for numbers, names and buttons; Nunito for sentences. Both are bundled with the game.

WCAG 2.2 AAStatus: stable

Overview

Fredoka is round and loud: it sets the flash card, titles, nicknames, the room code and every button. Nunito sets the sentences that explain. Body text is 16px and semibold so it holds up on a small, bright screen; nothing is smaller than 12px. The fonts are files in assets/fonts/ under the SIL Open Font License, never loaded from a CDN.

Usage

  • Numbers and times use tabular figures (.numeric) so they do not jiggle as they change.
  • Headings balance their lines; sentences stay under about 26rem wide.
  • A title is cut with an ellipsis only where a wrap would break the layout (the top bar, the nickname). Names in lists wrap.
  • Use a role shorthand (font: var(--text-h2)), not a size and a weight by hand.

Accessibility

  • All sizes are in rem and the layout holds at 200% zoom.
  • Body is 16px; the smallest text is 12px and is never the only carrier of something needed to play.
  • The room code is spaced wide and spelled for a screen reader.
