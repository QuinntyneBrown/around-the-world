Iconography

Round line icons on a 24-unit grid with a 2.5px stroke, in the colour of the text beside them.

WCAG 2.2 AAStatus: stable
  • Overview
  • The set
  • Sizes
  • Usage

Overview

Icons are inline SVG and take currentColor. They are chunky to match Fredoka. An icon helps a word; only a handful of corner controls are an icon alone, and each of those has a spoken name.

Sizes

Small 20px (in text buttons), default 24px, large 32px (Delete on the number pad), extra large 40px (badges, notices)

Usage

  • Beside a word, an icon is decorative: aria-hidden="true".
  • An icon alone is inside an Icon button with an aria-label.
  • A state is never an icon’s colour alone: muted shows a different icon; mic off shows a crossed mic.
  • The kids are not icons. They are portraits, or bean-bodied pieces on the World Map.
