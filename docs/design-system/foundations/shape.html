Foundation

Shape

Everything is round. The bigger the thing, the bigger its corners.

WCAG 2.2 AAStatus: stable
  • Overview
  • Radii
  • Border widths
  • Usage
  • Tokens

Overview

Five radii and a full round. Edges are 2px and drawn inside the shape, so sizes never change with a state.

Radii

--radius-xs
--radius-sm
--radius-md
--radius-lg
--radius-xl
--radius-full
RadiusUsed for
xs 8pxSkeleton lines
sm 12pxCode letters, text buttons, small portraits
md 16pxToy buttons, keys, chips, portraits
lg 24pxSmall panels, player cards, the HUD, toasts
xl 32pxPanels, the flash card, dialogs, the passport
fullPills, tags, badges, the timer bar, round portraits

Border widths

TokenValueUsed for
--border-width-hairline
--border-width-thick
--border-width-heavya selected kid, the code boxes
--border-width-stampthe passport stamp, the flash card's result ring

A dashed edge means “a place for something”: an empty desk, a stamp.

Usage

  • Use the radius for the element’s size from the table; do not invent one.
  • A selected thing gets a heavier edge and a tick or dot, never a different shape.
