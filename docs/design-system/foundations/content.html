Content

Short, warm and plain: the words a ten-year-old would say across a classroom.

Overview

The game talks like a friendly classmate. Sentences are short. It never blames, never shouts and never uses a grown-up’s word where a child’s will do.

Rules

  • Sentence case everywhere. Capitals only for names and the room code.
  • A button is a verb: Play, Join, Go!, Start the race. Never OK, Yes, No, Submit or Cancel.
  • Numbers are figures: “4 letters”, “12 desks”, “8 kids max”.
  • Use “you”. The child’s own entry in a list is “You”.
  • One exclamation mark at most, and only for good news.
  • Canadian and British spelling: maths, colour.

Formulas

Never

  • A field for free text, anywhere. The room code is the only thing typed.
  • Text a language model wrote. A classmate reacts with a fixed animation or one of the six stickers.
  • The backend’s own error message, a code or a stack trace.
  • Anything that asks for a name, an age, an email address or money.
