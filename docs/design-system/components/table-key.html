Table key

One times table, from ×2 to ×12, that is on or off.

Overview

Eleven square keys in a grid. “Easy” turns on 2, 3, 4, 5 and 10; “All” turns on every one. When Times is off the keys are disabled.

Anatomy

  1. KeySquare, 16px radius
  2. Label×n, Fredoka bold
  3. DotTop right when on

Variants

The grid with 2 to 10 on

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility
