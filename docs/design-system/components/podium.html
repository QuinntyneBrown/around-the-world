Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

A native <ol> in place order for a screen reader (1st, 2nd, 3rd) even though 2nd is drawn first.

Keyboard

It is not focusable and takes no keys.

Focus

It never takes focus; focus passes to the controls around it.

Labelling

Rank has aria-label “1st place”. Pictures are decorative; the name is on the step.

Contrast

Motion

Third, second, then first rise in turn, each in under 300 ms. Reduced motion fades them.

Touch

It is not a target, so it needs no target size.

Content

  • Won: “You went around the world!”. Otherwise: “{Name} made it round first!”.
  • Time ran out: “Time’s up! You travelled furthest!”.
  • Everyone else left a game with friends: “You travelled furthest!”, with “{n} desks out of {tour length}.” before the cheer (podium/everyone-left, ADR 0036).
  • The line under is the winner’s cheer.
