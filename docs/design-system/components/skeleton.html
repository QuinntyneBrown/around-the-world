Skeleton

Grey shapes in the layout of what is arriving.

Overview

A skeleton holds the place of content so nothing jumps when it arrives. It takes the size of the thing it stands for.

Anatomy

  1. ShapeThe size and radius of the real thing
  2. ShimmerA slow sweep

Variants

Text, title, block, round, panel
HTML
<div class="stack" style="width: 16rem;"><span class="skeleton skeleton--text"></span><span class="skeleton skeleton--title"></span><span class="skeleton skeleton--block portrait"></span><span class="skeleton skeleton--round timer-bar"></span></div>

Sizes

It takes its size from the class it stands in for: <code>.skeleton.portrait</code>, <code>.skeleton.toy-btn</code>.

States

State ofOn the pageOn a panel
Skeleton

Both themes

Responsive behaviour

It follows the layout it stands in.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

aria-hidden="true". The container has aria-busy="true" and a visually hidden role="status" that says what is arriving.

Keyboard

It is not focusable and takes no keys.

Focus

It never takes focus; focus passes to the controls around it.

Labelling

“Getting the room…”, “Drawing the classroom…”.

Contrast

Shape on the page (decorative)
Shape on the page (decorative)

Motion

The shimmer sweeps every 1.4 s (--duration-sweep). Reduced motion stops it.

Touch

It is not a target, so it needs no target size.

Content

  • The hidden status says what is arriving, in a child’s words.
