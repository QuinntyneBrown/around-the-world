Code field

The four boxes a child types a room’s code into. It is the only thing in the game that is typed.

Overview

One real text input lies invisible over four boxes that show what was typed. Only letters are taken, shown as capitals, four at most.

Anatomy

  1. InputInvisible, over the boxes
  2. Box4 : 5, 16px radius, 4px edge
  3. Waiting boxAccent edge
  4. LetterFredoka bold 48px

Variants

It has one look.

One size: at most 384px wide.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

A native <input type="text" maxlength="4"> inside a <label>. Help and the message are joined with aria-describedby; an unknown code sets aria-invalid="true".

Keyboard

KeyAction
LettersFill the boxes, as capitals.
BackspaceRemoves the last letter.
EnterJoins when there are four.

Focus

The waiting box takes the shared ring while the input has focus.

Labelling

“Room code”, visually hidden; the help text says where the code comes from.

Motion

An unknown code shakes the boxes once in 300 ms; with reduced motion only the colour changes.

Touch

Each box is taller than 44px; the whole field is one target.

Content

  • Help: “Ask the friend who made the room. It’s 4 letters.”
  • Errors are a child’s words and say what to do: “Hmm, no room with that code. Check the letters?”
