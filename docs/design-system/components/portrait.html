Portrait

A kid’s picture on their own colour.

Overview

The portrait is how a child recognises a kid. It is always on that kid’s colour, set with data-kid. Beside a name it is decorative; alone it carries the kid’s name as its alt.

Anatomy

  1. PictureSquare, cropped to cover
  2. ColourThe kid’s colour shows while it loads

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

An <img>. With the kid’s name beside it, alt=""; alone, alt is the kid’s name.

Keyboard

It is not focusable and takes no keys.

Focus

It never takes focus; focus passes to the controls around it.

Labelling

Never the only carrier of who a kid is: the name is written nearby.

Contrast

The colour is a background, not text
The colour is a background, not text

Motion

On Pick Your Kid the chosen kid fades and rises in 200 ms; reduced motion only fades.

Touch

It is not a target, so it needs no target size.

Content

  • Alt text is the kid’s name, nothing more.
