Icon button

A square toy button that holds one icon: Back, sound, Settings, Pause, Leave, copy.

WCAG 2.2 AAStatus: stableBlock .icon-btn

Overview

Use it for a corner control whose meaning an icon carries and whose name a screen reader reads. If the action needs words to be understood, use a text button.

Anatomy

  1. Icon24px, 2.5px stroke
  2. Face48 × 48px, 16px radius
  3. Base6px ledge

Variants

On a screen
HTML
<button type="button" class="icon-btn" aria-label="Back"><svg class="icon" aria-hidden="true">…</svg></button><button type="button" class="icon-btn" aria-label="Mute sound"><svg class="icon" aria-hidden="true">…</svg></button><button type="button" class="icon-btn" aria-label="Settings"><svg class="icon" aria-hidden="true">…</svg></button><button type="button" class="icon-btn" aria-label="Pause"><svg class="icon" aria-hidden="true">…</svg></button><button type="button" class="icon-btn" aria-label="Leave the game"><svg class="icon" aria-hidden="true">…</svg></button>
On the room code
HTML
<div class="room-code"><button type="button" class="icon-btn icon-btn--on-code" aria-label="Copy room link"><svg class="icon" aria-hidden="true">…</svg></button></div>

Sizes

One size: 48 × 48px.

States

VariantDefaultHoverFocusActiveDisabledPressed (muted)
Default

Both themes

Responsive behaviour

It is the same at every width.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

A native <button>, or <a> for Back. The sound button is a toggle with aria-pressed.

Keyboard

KeyAction
TabMoves focus to the button.
EnterPresses it.
SpacePresses it.

Focus

The shared ring: 4px of --color-focus-ring, 3px away from the edge, on :focus-visible.

Labelling

aria-label says what pressing it will do: “Mute sound” when sound is on, “Turn sound on” when it is muted.

Contrast

Icon on its face
Face against its base
Focus ring on the page

Motion

Pressing sinks the face onto its base in 120 ms (--duration-fast). With reduced motion it does not move.

Touch

48 × 48px.

Content

  • The label is an action: “Back”, “Pause”, “Copy room link”.
  • The sound button’s label changes with its state; so does its icon.
