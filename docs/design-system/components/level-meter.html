Level meter

Bars that move with the child’s voice, on Mic Check and inside “Shout it!”.

Overview

It shows that the microphone hears something. It is decoration for a state that is always also said in words.

States

State ofMovingReduced motion
Meter

The bars hold still at their heights.

Both themes

Responsive behaviour

Centred on a phone, left-aligned beside the listener from 768px.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

aria-hidden="true".

Keyboard

It is not focusable and takes no keys.

Focus

It never takes focus; focus passes to the controls around it.

Labelling

None: the heading says “Bolt is listening”.

Contrast

Bars on the page
Bars on the page

Motion

Each bar beats in 600 ms (--duration-pulse), a third of a beat apart. Reduced motion stops them.

Touch

It is not a target, so it needs no target size.

Content

  • No words.
