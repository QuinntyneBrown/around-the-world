Dialog

A question over the screen that must be answered before going on: Paused, Leave the game?, Settings.

Overview

Use a dialog when the game has stopped for a decision. The safe choice is the big button and takes focus. There are three: Pause (solo), Leave Game (friends) and Settings.

Anatomy

  1. BackdropDims the screen, which takes no input
  2. Titleh2
  3. CloseAn icon button; the same as the safe choice
  4. BodyOne or two sentences
  5. ActionsStacked: the safe one first and biggest

Variants

Accessibility

Role and pattern

WAI-ARIA Dialog (Modal): role="dialog" aria-modal="true", named by its title and described by its body. The screen behind is inert.

Keyboard

KeyAction
TabMoves between the dialog’s controls and stays inside it.
EscapeCloses it with the safe choice: keep playing, stay.
EnterPresses the focused button.

Focus

Focus starts on the safe choice and returns to the button that opened the dialog.

Labelling

The title names it; Close is named for what it does: “Keep playing”.

Motion

Slides up as a sheet under 576px, scales in from the centre above, in 320 ms. Reduced motion fades it.

Touch

Buttons are 56px tall or more.

Content

  • The title is the state or the question: “Paused”, “Leave the game?”.
  • Buttons say what they do: “Keep playing”, “Go home”, “Stay and play”, “Leave”. Never Yes, No, OK or Cancel.
