Notice

A whole screen with one message and one way on: an address that leads nowhere, or the game tripping over.

WCAG 2.2 AAStatus: stableBlock .notice

Overview

Use it when there is nothing else to show. It always offers Home.

Anatomy

  1. ArtA 96px circle with an icon
  2. Titleh1
  3. TextOne or two sentences
  4. ActionHome, and Try again when it could help
