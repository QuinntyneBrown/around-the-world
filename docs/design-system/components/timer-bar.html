Timer bar

The bar that drains over a flash card’s time, in the traveller’s colour.

WCAG 2.2 AAStatus: stableBlock .timer-bar

Overview

10 seconds for Chill, 6 for Normal, 3 for Lightning. It stops, faded, once the duel is decided.

Anatomy

  1. Track12px, fully rounded
  2. FillThe traveller’s colour, with a 1px deeper edge

Variants

In each kid’s colour

Sizes

One size.

States

State ofFullDrainingNearly outStopped
Timer

Both themes

Responsive behaviour

It is the same at every width.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

role="progressbar" with aria-valuenow in seconds and aria-valuetext “4 seconds left”.

Keyboard

It is not focusable and takes no keys.

Focus

It never takes focus; focus passes to the controls around it.

Labelling

“Time to answer”.

Contrast

Track on the panel
Track on the panel

Motion

It drains in a straight line over the card’s time. Reduced motion keeps it: it is a clock, not decoration.

Touch

It is not a target, so it needs no target size.

Content

  • No numbers on the bar; the value text carries them.
