Kid picker

The roster of five kids on Pick Your Kid. One is always chosen.

WCAG 2.2 AAStatus: stableBlock .kid-picker

Overview

Five toggle buttons in a row. Choosing one brings that kid forward with their name, tagline and description, and changes the confirm button to “I’m {kid}!”.

Anatomy

  1. OptionA button per kid
  2. PortraitFills the option’s width
  3. NameWith a tick when chosen
  4. Chosen edge4px in the kid’s deep colour

Variants

It has one look.

Sizes

One size; the options share the width equally.

States

State ofZuri chosenKenji hoveredKenji focusedPip chosen
Roster

Both themes

Responsive behaviour

WidthWhat changes
Under 576pxFive across with 8px gaps; names 14px.
576px and up16px gaps; names 18px.
992px and upIn the second column, beside the chosen kid.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

A role="group" labelled “Choose a kid”, holding five <button aria-pressed>. Exactly one is pressed.

Keyboard

KeyAction
TabMoves from kid to kid.
Enter or SpaceChooses the kid.

Focus

The shared ring: 4px of --color-focus-ring, 3px away from the edge, on :focus-visible.

Labelling

Each button’s name is the kid’s name. The stage beside it is a live region, so the tagline is read when the choice changes.

Contrast

Name
Name when chosen
Name
Name when chosen

Motion

The chosen kid fades in over 200 ms.

Touch

Each option is at least 60px wide at 320px and taller than 44px.

Content

  • Names only: Zuri, Kenji, Nia, Milo, Pip.
