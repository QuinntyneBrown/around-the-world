Spinner

A small turning ring inside a busy button.

WCAG 2.2 AAStatus: stableBlock .spinner

Overview

Use it only inside a button that was just pressed, before the words that say what is happening. For a screen that is arriving use skeletons.

Anatomy

  1. Ring20px, 3px, the label’s colour

Variants

In a busy button
HTML
<button type="button" class="toy-btn toy-btn--friends" aria-busy="true"><span class="spinner" aria-hidden="true"></span> Joining…</button><button type="button" class="toy-btn" aria-busy="true"><span class="spinner" aria-hidden="true"></span> Saving…</button><button type="button" class="toy-btn toy-btn--paper" aria-busy="true"><span class="spinner" aria-hidden="true"></span> Leaving…</button>

Sizes

One size: 20px.

States

State ofTurningReduced motion
Spinner

It holds still; the words carry it.

Both themes

Responsive behaviour

It is the same at every width.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

aria-hidden="true". The button has aria-busy="true" and its words say what is happening.

Keyboard

It is not focusable and takes no keys.

Focus

It never takes focus; focus passes to the controls around it.

Labelling

None of its own.

Contrast

On the friends button
On the friends button

Motion

One turn every 800 ms (--duration-spin). Reduced motion stops it.

Touch

It is not a target, so it needs no target size.

Content

  • Always beside words ending in an ellipsis: “Joining…”.
