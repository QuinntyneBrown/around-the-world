Nickname

The generated game name and the button that rolls another. Nothing can be typed.

Overview

A nickname is one adjective and one animal from fixed lists. “New name” rolls a different one. There is no field: a child never types a name.

Anatomy

  1. Label“Your game name”
  2. NicknameFredoka semibold, cut with an ellipsis if long
  3. New nameA paper toy button with dice
  4. ReasonWhy there are no real names

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.
