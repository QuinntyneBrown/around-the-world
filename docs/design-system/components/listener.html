Listener

Milo and Bolt in a circle on Mic Check, with a badge that says whether the microphone hears.

Overview

Bolt is the one listening. The badge is a microphone, a tick when the child was heard, or a crossed microphone when the mic is off.

Anatomy

  1. PictureA circle, Milo with Bolt
  2. RingsOnly while listening
  3. BadgeMic, tick or mic off

Variants

Asking, listening, heard, mic off

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

An image with alt text; the badge is decorative because the heading beside it says the same in words.

Keyboard

It is not focusable and takes no keys.

Focus

It never takes focus; focus passes to the controls around it.

Labelling

Alt: “Milo and his robot Bolt”.

Contrast

Badge icon
Mic off badge
Badge icon
Mic off badge

Motion

Two rings grow and fade every 1.4 s while listening. With reduced motion there are no rings.

Touch

It is not a target, so it needs no target size.

Content

  • The state is always in the heading too: “Shout ‘Ready!’”, “Bolt heard you!”, “Bolt can’t hear you”.
