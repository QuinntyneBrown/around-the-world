Code letters

Four letters in boxes: a picture of what a room code looks like.

Overview

It shows, before a room exists, that a code is four letters. It is not the room’s code and not a field.

Anatomy

  1. Box56px, 12px radius
  2. LetterFredoka bold, accent colour

Responsive behaviour

It is the same at every width.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

role="img" with a label that spells the letters.

Keyboard

It is not focusable and takes no keys.

Focus

It never takes focus; focus passes to the controls around it.

Labelling
