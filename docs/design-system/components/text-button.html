Text button

A quiet action in words: Change, Easy, All, “Too noisy? Tap answers instead”, “Use number pad”.

Overview

Use it for an action that is not the screen’s way on. The pill form floats over the classroom on Duel.

Anatomy

  1. Icon (optional)20px
  2. LabelFredoka semibold, in the accent colour
  3. Hit area44px tall, 12px radius, shows on hover

Variants

Plain, with an icon, and as a pill
HTML
<button type="button" class="text-btn">Too noisy? Tap answers instead</button><button type="button" class="text-btn"><svg class="icon" aria-hidden="true">…</svg>Change</button><button type="button" class="text-btn text-btn--pill"><svg class="icon" aria-hidden="true">…</svg>Use number pad</button>

Sizes

One size: 44px tall.

States

VariantDefaultHoverFocusActiveDisabled

Responsive behaviour

It is the same at every width.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

A native <button>, or <a> when it goes to another screen.

Content

  • Say what happens in a child’s words.
  • A question may come first when it explains why: “Too noisy? Tap answers instead”.
