Number pad

Twelve keys for answering by tapping: the digits, Delete and Go.

WCAG 2.2 AAStatus: stableBlock .number-pad

Overview

The fallback for the voice: used when the browser cannot listen, the mic is refused, or the room is too noisy. Up to three digits; Go gives the answer.

Anatomy

  1. DigitWhite toy key
  2. DeletePale blue, removes the last digit
  3. GoGreen, gives the answer

Variants

It has one look.

Sizes

Keys are 56px tall, 64px from 576px, and 44px on a short screen.

States

Both themes

Responsive behaviour

WidthWhat changes

Under 672px tallKeys are 44px so the pad and the card are both whole.

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

A role="group" labelled “Number pad” of native buttons.

Keyboard

KeyAction
0 to 9Press that digit.
BackspaceDelete.
EnterGo.
TabMoves through the keys in reading order.

Focus

The shared ring: 4px of --color-focus-ring, 3px away from the edge, on :focus-visible.

Labelling

Digits are their own names; the icon key is “Delete”; the green key is “Go”.

Motion

Pressing sinks the face onto its base in 120 ms (--duration-fast). With reduced motion it does not move. A digit shows on the card within 100 ms.

Touch

Never smaller than 44px tall; about 100px wide.

Content

  • Go, not Enter or OK.
