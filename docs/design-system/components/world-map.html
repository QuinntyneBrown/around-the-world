Overview

This is the drawn stand-in for the 3D classroom on World Map. It is a picture, so its colours are the same in light and dark. The interface over it (the header, the message, the standings) is what the design system governs.

Over the 3D classroom. The drawn room stands in while the 3D classroom loads. Once the classroom is drawn, the room keeps only its labels (the name tags and the country plaques), drawn at the same places over the 3D room, which is framed to the same plan (ADR 0028); in code this is labelsOnly. On a device that cannot draw the classroom, the still picture takes the room's place with the alert "The map is having a rest" (the world-map/error mock).

Anatomy

  1. Floor and rugAn isometric slab; the rug is a world map
  2. DeskLit when it is here or next
  3. KidA bean-bodied piece with one accessory each
  4. Name tagOver the five kids and you
  5. Country plaqueNavy for the start, blue for the next stop

Theming

It reads semantic tokens only, so it follows the theme with no rule of its own. To restyle it, override its component custom properties or the semantic tokens listed under Tokens; never write a colour into the component.

Accessibility

Role and pattern

role="img" with a label that says the tour length, where the child is and who is travelling. The same is in the header’s line of text.

Keyboard

It is not focusable and takes no keys.

Focus

It never takes focus; focus passes to the controls around it.

Labelling

The standings below carry every position as text.

Contrast

Plaque text
Plaque text

Motion

The traveller walks the dotted path to the next desk in about a second. With reduced motion the kid fades from one desk to the next.

Touch

It is not a target, so it needs no target size.

Content

  • Plaques carry the country’s name. With more than 6 desks only the start, here, next and your own desk are labelled.
