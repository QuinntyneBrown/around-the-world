# 002 · New name dice

On a phone, the dice are the only visible label for the button that rolls a new nickname. The game showed a 24 px single die with five pips. Pick Your Kid uses two overlapping dice, four visible pips, a 20 px box and a 2.5-unit stroke. The game and four mock states now use that drawing.
